# Bijoux E-commerce (PHP)

## Description

Ce projet est un site e-commerce développé en PHP et MySQL permettant la gestion d'une boutique de bijoux.

Il comprend un espace client et un espace d'administration pour gérer les produits, les commandes et les utilisateurs.

Projet réalisé dans le cadre d'un cours de développement Web.

---

## Fonctionnalités

- Catalogue de bijoux
- Inscription et connexion des utilisateurs
- Gestion du panier
- Validation des commandes
- Interface d'administration
- Gestion des produits
- Gestion des utilisateurs

---

## Technologies

- PHP
- SQL
- HTML
- CSS
- Javascript

---

## Structure du projet

- `accueil.html` → Page d'accueil
- `boutique.php` → Catalogue des produits
- `panier.php` → Gestion du panier
- `commande.php` → Validation des commandes
- `admin_dashboard.php` → Tableau de bord administrateur
- `gerer_produit.php` → Gestion des produits
- `gerer_utilisateurs.php` → Gestion des utilisateurs
- `bdd.sql` → Structure de la base de données

---

## Installation

1. Importer `bdd.sql` dans MySQL.
2. Modifier les paramètres de connexion dans `config.php` si nécessaire.
3. Placer le projet dans le dossier du serveur web (XAMPP/WAMP).
4. Ouvrir le projet depuis votre navigateur.
